# Thesis supporting materials

Selected code and analysis materials for João Coelho's dissertation on digital information management in cultural and scientific institutions.

This repository contains reviewed publication copies. It is separate from the working folders and does not contain the full dissertation, correspondence, credentials or operational backups. Privacy edits and exclusions are documented in `docs/`.

## Organization

- `shared/wordpress-audit/`: reusable Python scripts used to analyze the public WordPress APIs of EPHEMERA and the ACL.
- `cases/ephemera/`: statistics, analysis documents, audit outputs and selected Wikibase/Tainacan prototype materials.
- `cases/acl/`: analysis documents, reviewed audit outputs and anatomical-model PDF generation code.
- `cases/correia-da-serra/`: context and links to the application repository.
- `cases/illlp/`: context and links to the dictionary and vocabulary application.

See [the materials index](docs/materials-index.md) for the 1 October 2026 deposit and exclusions. Historical reports retain their original dates and may describe an earlier implementation stage. They do not certify the current state of the institutional services.
