# Thesis supporting materials

Selected code and analysis materials for João Coelho's dissertation on digital information management in cultural and scientific institutions.

This repository contains reviewed publication copies. It is separate from the working folders and does not contain the full dissertation, correspondence, credentials or operational backups.

## Organization

- `shared/wordpress-audit/`: reusable Python scripts used to analyze the public WordPress APIs of EPHEMERA and the ACL.
- `cases/ephemera/`: statistics, analysis documents, audit outputs and selected Wikibase/Tainacan prototype materials.
- `cases/acl/`: analysis documents, reviewed audit outputs, anatomical-model PDF generation code and the delivered PDF.
- `cases/correia-da-serra/`: a redacted bibliographic dataset and links to the application repository.
- `cases/illlp/`: selected XML analysis reports and scripts, and links to the dictionary and vocabulary application.

The selected materials were deposited on 1 October 2026. Historical reports retain their original dates and may describe an earlier implementation stage. They do not certify the current state of the institutional services.

## Publication copies and privacy

The published copies omit credentials, personal contacts, server-access details and private correspondence. Office documents were reviewed to remove sensitive content and internal metadata. The Correia da Serra spreadsheet contains 1,869 bibliographic records, without internal notes or editorial activity. The consolidated lexical XML, operational logs, backups, database dumps and Docker volumes are not included.

Original working files remain outside this repository. These privacy edits do not change the dates or status of the historical findings. Private operational data for the dictionary and vocabulary remain in a separate restricted repository.
